# Base ROM

This repository holds none of the game. Put your own dump here, under the name below, and check that it is the
version the project is for: `configure.py` and `ninja` refuse any other.

| Version    | File name                  | Game code | SHA-1                                      |
| ---------- | -------------------------- | --------- | ------------------------------------------ |
| `jpn_rev1` | `baserom_jpn_rev1.nds`     | `CCUJ`    | `f37d5ff0e3444cf3fab38890efb71f4f14c96994` |

This is the ROM that No-Intro lists as "Tomodachi Collection (Japan) (Rev 1)", with its secure area decrypted, which
is how dumps are normally distributed.
